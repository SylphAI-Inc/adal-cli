# Integrations

Connect AdaL CLI to your development tools and services using the Model Context Protocol (MCP). Extend AdaL's capabilities with integrations for project management, version control, databases, and more.

## What You'll Learn

### [Overview](./overview.md)
Discover available integrations for AdaL CLI. Learn how to connect with Linear, GitHub, Notion, Slack, PostgreSQL, and other services to streamline your workflow.

### [MCP Support](./mcp-support.md)
Understand the Model Context Protocol that powers AdaL's integrations. Learn how to add, configure, and manage MCP servers. Build custom integrations for your specific needs.

---

## Popular Integrations

**Project Management:**
- **Linear** - Create issues, update status, query tasks
- **Jira** - Manage tickets and sprints

**Version Control:**
- **GitHub** - Manage repos, PRs, issues
- **GitLab** - CI/CD integration

**Documentation:**
- **Notion** - Read/write docs and knowledge bases
- **Confluence** - Team documentation

**Databases:**
- **PostgreSQL** - Query and analyze data
- **MySQL** - Database operations

**Communication:**
- **Slack** - Send messages and notifications
- **Discord** - Team coordination

---

## Getting Started

1. **Check available integrations:** `/mcp list`
2. **Add an integration:** `/mcp add [service]`
3. **Configure credentials:** Follow the setup prompts
4. **Start using:** Reference the service in your commands
