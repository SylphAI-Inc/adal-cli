# Contributing to AdaL CLI

Thank you for your interest in contributing to AdaL CLI! This guide will help you get started with contributing and staying updated with the project.

## 📬 Getting Notifications for Issues

There are several ways to receive automatic notifications for issues and activity on this repository:

### 1. Watch the Repository (Recommended)

To receive notifications for all issues, pull requests, and discussions:

1. **Click the "Watch" button** at the top-right of the [repository page](https://github.com/SylphAI-Inc/adal-cli)
2. **Select your notification level:**
   - **All Activity** - Get notified for all issues, PRs, discussions, and releases
   - **Issues, PRs, & Releases** - Get notified for new issues, pull requests, and releases only
   - **Releases only** - Only get notified when new releases are published
   - **Ignore** - Don't receive notifications (you can still manually subscribe to specific issues)

### 2. Automatic Subscriptions

You're automatically subscribed to notifications for:
- Issues **you create**
- Issues **you comment on**
- Pull requests **you open or are assigned to**
- Conversations where you're **@mentioned**

### 3. Custom Notification Settings

Configure how you receive notifications:

1. Go to your [GitHub notification settings](https://github.com/settings/notifications)
2. Choose between:
   - **Email notifications** - Receive notifications via email
   - **Web notifications** - See notifications in the GitHub UI only
   - **Both** - Get both email and web notifications

### 4. Subscribe to Specific Issues

To get notifications for a specific issue without watching the entire repository:

1. Open the issue you're interested in
2. Click the **"Subscribe"** button on the right sidebar
3. You'll receive notifications for all future comments and updates on that issue

### 5. GitHub Mobile App

Install the [GitHub Mobile App](https://github.com/mobile) to receive push notifications on your phone for issues and updates.

## 🐛 Reporting Issues

Found a bug or something wrong in the docs?

**[Open an Issue →](https://github.com/SylphAI-Inc/adal-cli/issues/new)**

Please include:
- What you expected vs what happened
- Steps to reproduce (if applicable)
- AdaL CLI version (`adal -v`)
- OS and terminal

## 📝 Contributing Documentation

We welcome documentation improvements!

### Quick Edits

1. Find the page you want to fix at [docs.sylph.ai](https://docs.sylph.ai)
2. Locate the corresponding file in `docs-site/docs/`
3. Edit and submit a PR

### Running Locally

```bash
cd docs-site
npm install
npm run start    # Dev server at http://localhost:3000
npm run build    # Production build
```

### Guidelines

- Keep docs clear and concise
- Test changes locally with `npm run build`
- Follow existing formatting conventions

## 📋 Pull Request Process

1. **Fork the repository** and create a new branch for your changes
2. **Make your changes** following the code style and conventions
3. **Test your changes** locally (run `npm run build` in `docs-site/`)
4. **Submit a pull request** with a clear description of what you've changed and why
5. **Wait for review** - A maintainer will review your PR and may request changes
