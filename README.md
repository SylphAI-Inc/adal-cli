# ADAL CLI Documentation

This repository contains the public documentation site for ADAL CLI, built with Docusaurus.

## Overview

AdaL CLI is your AI companion for engineering and research.

## Documentation Site

This site provides comprehensive documentation including:

- Quickstart guide
- API Reference
- Tutorials and Examples
- Advanced Topics
- Community Resources

## Development

```bash
cd docs-site

# Install dependencies
npm install

# Start development server
npm run start

# Build for production
npm run build
```
