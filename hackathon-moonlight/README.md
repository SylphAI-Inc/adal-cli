# @skills Hackathon Presentation — Moonlight

Presentation page for the `@skills:` protocol and `atskills.one`, extended with
the paper preview, demo video, and social/CTA sections.

## Public page

After this folder is merged and Pages picks it up:

<https://sylphai-inc.github.io/adal-cli/hackathon-moonlight/>

## Present locally

From the repository root:

```bash
python3 -m http.server 4173
```

Open:

<http://127.0.0.1:4173/hackathon-moonlight/>

## Source

The presentation is a self-contained HTML page with local assets:

- `hackathon-moonlight/index.html`
- `hackathon-moonlight/assets/` — cover image, paper page previews, demo video

Edit the HTML directly, then preview it with the local server before pushing changes.
