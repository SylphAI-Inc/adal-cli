Use an existing skill

Use skills without installing them to avoid bloating the system prompt.

  1. 01 Choose a source GitHub gh: or the hub: on atskills.one.
  2. 02 Use once @skills:<path> For example, gh:owner/repo or hub:creator/skill.
  3. 03 Save @skills:<path>:save Keep it in the project.
  4. 04 Auto-load @skills:<path>:install Or configure it through /skills in AdaL.

Turn an expensive first pass into a reusable skill

Stop repeating completed work and reuse the same playbook across projects and agents.

  1. 01 Capture SKILL.md Write down the working process.
  2. 02 Store .atskills/ or hub: Keep it in the project or publish it to the hub.
  3. 03 Share @skills:<path> Give one path to the team.
  4. 04 Manage /skills · atskills.one Use the AdaL CLI or the skills dashboard.
